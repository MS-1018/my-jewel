# Jewel Survival 💎

スマホで遊ぶことを前提に開発した、爽快パズルゲームです！

## 🚀 遊び方
このゲームは **スマートフォン（タッチ操作）専用** です。
PCのブラウザで開いている場合は、ブラウザの「デベロッパーツール」でスマホ表示に切り替えるか、実機のスマホで以下のURLにアクセスしてください。

**[https://ms-1018.github.io/my-jewel/]**

### 🎮 ゲームルール
- 宝石をスワイプして、**「縦・横に3つ」** または **「2×2の四角形」** に並べると消去！
- 消えるたびに残り時間が回復します。
- 連鎖（Combo）が続くとスコア倍率がアップ！
- 制限時間内にどれだけスコアを稼げるか挑戦しよう！

### ✨ 特徴
- AIとの共同開発によるプロトタイプ
- 2×2の四角形消しルール搭載
- 連鎖に応じたパーティクル演出とサウンド変化
- ハイスコアのローカル保存機能
